# TaskFlow – פרויקט מסכם פיתוח אפליקציות אינטרנטיות

מערכת לניהול משתמשים, פרויקטים ומשימות, עם Node.js, Express, MongoDB/Mongoose, MVC, jQuery AJAX, React, Socket.io וגרפים מבוססי נתוני MongoDB.

## התקנה במק
1. חלצי את ZIP לתיקייה נפרדת, למשל `TaskFlow-Complete`.
2. בטרמינל של VS Code בתוך התיקייה הריצי `npm install`.
3. צרי `.env` על בסיס `.env.example` והכניסי את כתובת MongoDB Atlas האישית. **אין להעלות את `.env` ל-GitHub**.
4. הריצי `npm start` ופתחי http://localhost:3000.
5. סדר יצירת נתונים: קודם משתמש, אחר כך פרויקט, אחר כך משימה.

## מבנה MVC
- `models/` – שלושה מודלים Mongoose.
- `controllers/` – לוגיקת CRUD וחיפוש.
- `routes/` – נתיבי API.
- `public/` – View, jQuery AJAX, רכיב React, Canvas ו־CSS3.

## חיפושים
חיפוש חופשי לפי שם/תיאור, סינון סטטוס וסינון עדיפות משימות. כל החיפושים נעשים מול MongoDB.

## חשוב לפני הגשה
- לא נבדק מול חשבון Atlas שלך; חובה לבצע בדיקה מקומית.
- אין מערכת אימות והרשאות משתמשים; הצ'אט אינו שומר היסטוריה.
- מצורף סרטון MP4 קצר להדגמת תכונות TaskFlow בתיקיית `public/intro.mp4`.
- React משמש ברכיב הכותרת, ושאר ממשק ה־CRUD ב־jQuery.
- חלק מהספריות בצד הלקוח נטענות מ־CDN ולכן נדרש אינטרנט.
- לפני הגשה, בדקי את כל הדרישות המלאות של המרצה, מקוריות העבודה, קישור GitHub פתוח והגנה בעל פה.


## ממשק אינטראקטיבי
- Dashboard מעוצב עם ניווט צדדי, כרטיסי מדדים ומעקב התקדמות.
- לוח Kanban לפי סטטוס המשימות; שינוי סטטוס נשמר ב-MongoDB דרך API.
- מרכז התראות פנימי עבור משימות באיחור, להיום, למחר, ועד שלושה ימים קדימה (עדיפות גבוהה). התראות נוצרות מנתוני המשימות בעת טעינת האתר; אין שליחת הודעות מערכת או התראות Push.
- רכיבי הגרפים, הטפסים, הצ׳אט וסרטון intro.mp4 נשמרו.
- אין להעלות קובץ .env ל-GitHub.


## אימות דרישות המרצה (14.10.2026)
- Node.js + Express: `server.js`
- MongoDB + MVC: `models/`, `controllers/`, `routes/`, `public/`
- שלושה מודלים CRUD: User, Project, Task
- שאילתות חיפוש עם פרמטרים: טקסט, סטטוס, עדיפות, ותמיכה נוספת בפרויקט/אחראי בשרת
- jQuery + AJAX: `public/app.js`
- React + Video + Canvas: רכיב `MediaShowcase` ב־`public/app.js`, יחד עם שני גרפים סטטיסטיים מבוססי Canvas
- CSS3: text-shadow, transition, columns, @font-face, border-radius
- Socket.io: `server.js` ו־`public/app.js`
- סרטון קיים: `public/intro.mp4` (12 שניות)

**לא אומת מקצה לקצה:** התחברות למסד הנתונים של הסטודנטית, בדיקות דפדפן, גישה ל־CDN, זמינות המערכת במעבדה, והגשת GitHub ציבורי.
**לפני הגשה:** להעתיק `.env` מקומי לתיקיית הפרויקט, להריץ `npm install` ו־`npm start`, לבדוק את כל הפעולות בדפדפן, להעלות GitHub ציבורי ולוודא שאין סודות בקוד.


## TaskFlow Executive Pro – חדש

- ממשק Executive Dashboard אינטראקטיבי עם סינון לפי פרויקט, KPI, סיכונים, מועדי יעד ואחוזי התקדמות.
- יצוא Excel (`/api/reports/excel`) עם שלושה גיליונות: סיכום מנהלים, פירוט משימות ומצב פרויקטים.
- יצוא PowerPoint (`/api/reports/slides`) עם שש שקופיות ניהוליות.
- סיכום נתונים ב-JSON (`/api/reports/summary`).
- הנתונים נשלפים ממסד MongoDB בזמן יצירת הדוח, ולא מקובץ סטטי.
- הריצו `npm install` מחדש כדי להתקין `exceljs` ו-`pptxgenjs`, ואז `npm start`.
- יש להעתיק את `.env` מהתיקייה הקודמת (לא לשתף ולא להעלות ל-GitHub).
- מומלץ להשתמש במערכת רק בסביבה מקומית/לימודית: אין בה עדיין אימות משתמשים או הרשאות, והדוחות כוללים שמות משתמשים ופרטי משימות.
- רשימת המשימות ב-API מוגבלת ל-200 פריטים לצורכי ממשק; הדוחות נשלפים ישירות מה-DB ללא מגבלה זו.

### בדיקות נדרשות

1. להפעיל את הפרויקט עם MongoDB.
2. לבחור פרויקט ולוודא שמדדי ההנהלה משתנים.
3. לייצא Excel ולוודא ששלושת הגיליונות נפתחים עם נתונים נכונים.
4. לייצא PPTX ולוודא שש השקופיות נפתחות בעברית ומציגות מספרים תואמים.
5. לבדוק שהפונקציות הקיימות – CRUD, חיפוש, Kanban, צ'אט וגרפים – עדיין עובדות.
